安全靴・ネックストラップ・身だしなみ ↩️ リストへ戻る

  • 安全靴: つま先金属部の露出や靴底の著しい摩耗がないか日常点検を行う [source: 4]。夜間・ランプ内での視認性向上のため、かかと部に「反射テープ」が目視できる位置に貼り付けられていることを確認する [source: 4]。
  • ネックストラップ: 回転機器や可動部への巻き込まれ防止のため、強い力が加わると自動的に外れる「安全装置（分離機構）付き」の社内適合品であることを確認して着用する [source: 3]。
  • 服装: 袖口や裾が突起物や脚立等に引っかからないよう正しく着用し、ポケットには工具や部品を直接入れない（脱落・機体損傷防止） [source: 4]。

規程類・JV協定確認（指揮命令体系） ↩️ リストへ戻る

  • AQUAの確認手順: AQUAの [規程類 1] ➔ [JV協定書] ➔ [2 共同事業体における指揮命令の基本的な考え方] 等を参照し、指揮命令体系および指示手順を確認する [source: 3]。

作業分類および技術指示書確認 ↩️ リストへ戻る

    • 通常作業（Regular Work）: 定例作業（Routine Work：Departure, Arrival, A整備, C整備等）および非定例作業（Non-routine Work：不具合是正、故障探求、保存整備等） [source: 3]。
    • 特別作業（Project Work）: 改修・大修理・ワンタイムインスペクション等 [source: 3]。
  • 技術指示書・情報の種類と確認:
    • MM (Maintenance Manual): 機体作業基準 [source: 3]。
    • EO (Engineering Order): 計画的な改修・点検の実動指示 [source: 3]。
    • ED (Engineering Deviation): 規定やEOを越える不具合処置・対策指示 [source: 3]。
    • TSI (Technical Service Information): 技術的注意、助言、解説 [source: 3]。
    • TI / TR (Trouble Information / Report): 主要故障情報・評価記録 [source: 3]。
    • Bulletin: 整備規程・各種基準の補足説明・暫定処置・注意喚起 [source: 3]。

借用・管理要領

  • 使用時は管理表に「日付・所属・シフト・氏名・作業場所」を記入する [source: 3]。
  • 他ドックから一時借用する場合は、借用者名、日付、借用個数、作業場を明記して借用する [source: 3]。
  • 当日中に返却できない場合（長期借用）は、養生テープ等で第三者が容易に判別できるように「使用場所・長期借用」と明記して貼付しておく [source: 3]。

指差呼称（ONE POINT CALL）および実技基本姿勢 ↩️ リストへ戻る

  • 指差呼称の目的: 作業の要所要所で、誤判断・誤操作・誤作業を防ぎ、意識レベルを PHASE III（NORMAL CLEAR：意識明快）にギアチェンジして誤り発生率を約 1/6 に激減させる [source: 4]。
  • 実技基本姿勢・操作方法:
    • 背筋を伸ばし、左手は腰に当てる [source: 4]。
    • 親指を中指にかけた「縦拳（たてけん）」の形から、人さし指をまっすぐ突き出す [source: 4]。
    • 確認する対象（2°以内の視野）へ腕を伸ばして指で差し、目線で捉え、はっきりした声でコールする [source: 4]。
    • 呼称表現例: **「メカニカルロック、LOCK POSI、ヨシ！」「作動エリア確認、ヨシ！」「スイッチOFF、ヨシ！」** [source: 3, 4]

移動式スタンド・足場点検・設置要領 ↩️ リストへ戻る

  • 操作・設置手順:
    1. スタンドを移動通路マーキング線を塞がない位置まで移動させる [source: 4]。
    2. 床面接地ロック: ロックハンドルを時計回り（CW）に回し、接地フットを床面にしっかり接地させる [source: 3, 4]。
      注意: レール溝や凹凸のある床面に接地フットを降ろさないこと（スタンドが不安定になり転倒する恐れあり） [source: 3, 4]。
    3. 昇降・メカニカルロック確認:
      • 昇降後、不意の降下を防止する「メカニカルロック」ピン/レバーを操作する [source: 3]。
      • 必須目視点検: メカニカルロックが「LOCK POSI（LOCK状態）」に確実に噛み合っていることを指差呼称で目視確認する [source: 3, 4]。
  • 禁止事項: 人が乗ったままでのスタンド移動および昇降操作は厳禁 [source: 4]。

CARGO ACCESS STAND / CRS車（高所作業車）操作 ↩️ リストへ戻る

  • CARGO ACCESS STAND:
    • CARGO DOORにセットする充電式自走昇降スタンド [source: 3, 4]。
    • 設置要領: 機体に接近・セットする際は必ず監視員を配置する [source: 3, 4]。CARGO DOOR とスタンドの間に隙間ができないよう密着・セットする [source: 3, 4]。
  • CRS車（高所作業車）:
    • 電動自走式（高さ 2.2m, 4.2m, 6.2m） [source: 3, 4]。
    • 安全ルール: 高所作業車となるため、運転操作および作業時は必ず安全ベルト（フルハーネス）を着用する [source: 3, 4]。

格納庫大扉（ハンガードア）操作手順・注意事項 ↩️ リストへ戻る

警告: 大扉に挟まれ死亡事故に至った他社事例あり。手順と安全退避を厳守すること [source: 3, 4]。
  • 操作資格: CDC（チーフドックコントローラー）または CDCの許可を得た者 [source: 3, 4]。
  • 操作手順・安全ルール:
    1. 手動操作の徹底: 大扉操作時は、手動操作に限る [source: 3, 4]。
    2. 身体侵入の絶対禁止: 大扉の移動範囲内（隙間）に身体や上半身を絶対に入れないこと（上半身のみを入れた場合、扉の挟み込み防止センサーが作動しない可能性があり極めて危険） [source: 3, 4]。
    3. 環境確認・監視員配置: 操作前に周囲の安全を十分確認し、視認性が確保できない場合は必ず監視員を配置して操作する [source: 3, 4]。
    4. 大扉作動中は、移動範囲内に絶対に立ち入らない [source: 3, 4]。

危険物・有機溶剤の借用・色別管理・処置 ↩️ リストへ戻る

  • 保管場所: TOOL ROOM と No. 2 DOCK コントロールルームの中間に位置する「危険物庫」 [source: 3, 4]。
  • 容器の色別識別基準:
    • 水色（羽田）/ 白（成田）: ナフサ（機体一般 / CPC除去） [source: 3, 4]
    • 黄色（羽田）/ 緑（成田）: IPA (イソプロピルアルコール)（脱脂 / CABIN内消毒） [source: 3, 4]
    • 赤色（羽田）/ 黒（成田）: MPK (メチルプロピルケトン)（脱脂等） [source: 3, 4]
  • 借用台帳記入ルール: 員数管理されているため、借用時は台帳に「借用日・シフト・所属・氏名・作業場所・返却予定日」を明記する [source: 3, 4]。
  • 特記事項・養生:
    • MPKは劇物であり、コロガードペイント（WING, H-STAB）やプラスチックパーツ（CABIN内）を侵すため、飛散防止養生を徹底する [source: 3, 4]。
    • 残油は各ドックの廃油カートまたは危険物庫内ドラム缶に廃棄する [source: 3, 4]。

スプレー類・テープ類・CA材の点検基準 ↩️ リストへ戻る

  • スプレー類（保管：補給窓口前一時保管棚）:
    • WD-40（潤滑）, LPS3（防錆）, STEP21（電装洗浄）, ダイチェック（青:洗浄, 赤:浸透, 黄:現像）, LEAK DETECTOR（石鹸水）等 [source: 3, 4]。
    • 点検要領: 一点一様に「SERVICEABLE PARTS TAG」が添付されていること、および有効期限を超過していないことを目視確認する [source: 3, 4]。
  • テープ類（CA材 vs 補助テープ）:
    • CA材（Consumable A材料：機体構成材・タグ添付＆期限管理必須）: パーマセルテープ（床PNL防水）, アルミテープ（3M425/427等・応急/滑らかさ保持）, 両面テープ（カーペット）, オアコンテープ（ブランケット補修）, ガラステープ（CARGO目張り）, テフロンテープ（CHAFING防止） [source: 3, 4, 8]。
    • 整備作業補助テープ（機体に残して運航不可）: スコッチテープ, マスキングテープ, 養生テープ, ダンプロンテープ, ビニールテープ [source: 3, 4]。

オイル・作動油・油脂・オイラー識別 ↩️ リストへ戻る

  • オイル缶（1缶 = 1 QT）:
    • BP TURBO OIL 2380 / ESSO 2380（B767, B737, STARTER等） [source: 3, 4]。
    • BP TURBO OIL 2197 / ESSO 2197（B767, B787, B777 GE等） [source: 3, 4]。
    • MOBIL JET OIL II（B777 ENG/IDG/STARTER等） [source: 3, 4]。
    • 取扱い: 開封後の缶は絶対に戻さない。未使用缶は必ず箱に戻す [source: 3, 4]。
  • 作動油（FLUID）・専用カート:
    • SKYDROL LD4, HYJET V, Hydraunycoil FH6AW（SHOCK STRUT専用） [source: 3, 4]。
    • 厳禁: **作業時はカートの標記（SKYDROL LD4用 / FH6AW用 / HYJET V用）を絶対に間違えないこと** [source: 3, 4]。B787ヘSKYDROL LD4を入れることは禁止（5000psi未対応・EHSV不具合防止のためHYJET Vに統一） [source: 7]。
  • オイラーの管理: 容器の色が注油指定オイル・作動油と一致していることを確認する [source: 3, 4]。使用後は必ず空（クリア）にする [source: 3, 4]。

ウエス・軍手・保護具準備・オレンジウエス員数管理 ↩️ リストへ戻る

  • ウエスの種類と用途:
    • レンタルウエス: 一般整備作業（使用後はクリーニング） [source: 3, 4]。
    • ネルウエス: CABIN内清掃（羽田はTOOL ROOM洗濯BOXへ、成田は一般ゴミ） [source: 3, 4]。
    • フィルターウエス: サービシング時の流体（FLUID）ろ過 [source: 3, 4]。
    • 白ウエス: ペイント・シーラント作業（使用後廃棄） [source: 3, 4]。
    • オレンジウエス: **特定作業エリア（ENG, APU, FUEL TANK）専用** [source: 3, 4]。
  • オレンジウエス10枚員数管理手順（FOD・置き忘れ防止）:
    1. TOOL ROOMにて1箱（10枚セット＋返却用ビニール袋1枚）単位で借用する [source: 4]。
    2. 借用時、工具室担当者と共に「10枚であること」を相互確認する [source: 4]。
    3. 作業完了後、使用済みウエスを袋にまとめ、10枚揃っていることを相互確認して返却する [source: 3, 4]。1枚でも不足している場合は捜索完了まで機体をリリースできない [source: 4]。

トルクレンチ・トルクチェッカー実技操作手順 ↩️ リストへ戻る

測定範囲制限（QA INFO）: 機械式トルクレンチ（Preset式、Dial式、Beam式）は、**「最大トルク値の 20% 〜 100%」**の範囲でしか使用してはならない（20%未満は精度保証外） [source: 6]。
  • 点検・確認要領（持ち出し＆返却時）:
    1. 本体の有効期限ラベル（Due Date）を確認する [source: 6]。
    2. トルクチェッカー（LINE CHECKER）の電源を入れ、測定レンジ（0~175 in-lb / 300~1750 in-lb等）を確認する [source: 6]。
    3. トルクレンチを点検ポイント（最大値の約60%）にセットし、チェッカー上でゼロセット（0点調整）を行う [source: 6]。
    4. クリック音がするまで引いて締め付け、許容範囲（±5% = トルクレンチ精度±4% ＋ チェッカー精度±1%）以内であることを確認する [source: 6]。
  • トルクがけ実技注意事項:
    • ハンドルの着力点を握り、軸に対して直角に、滑らかかつ均一な力で引く [source: 6]。
    • クリック音がしたら直ちに引きを止める（二度締め厳禁） [source: 6]。
    • リミット式は使用後、必ず最小目盛りに戻して保管する（内部機構の永久変形防止） [source: 6]。

O-リング・バックアップリング取扱い完全手順 ↩️ リストへ戻る

  • 事前点検・取扱い基準:
    1. 取り外した旧品と新品の P/N・形状が同一であることを確認する（外観の色だけで選定しない） [source: 5]。
    2. 指でつぶして柔軟性を確認し、傷や亀裂がないか目視点検する [source: 5]。
    3. 旧品は再利用防止のため必ずカットして廃棄する [source: 5]。
    4. ラバー製O-リングは **50% 以上伸ばしてはならない**（テフロン等は5%以内） [source: 5]。
  • 実技装着手順（TSI 00-20-L038/L039）:
    1. ねじ山保護: ユニオン等の鋭利なねじ山（Thread）を通過させる際、ねじ山に O-リングパッケージ等のペーパーを巻きつけ、保護する [source: 5]。
    2. 潤滑: ペーパーおよびO-リングに指定の潤滑剤（ワセリン VVP236 / シリコングリス / MCS352 / 作動油等）を薄く塗布し、滑らせるように装着する [source: 5]。
    3. ねじれ除去: 装着後、指で全周をなぞり、O-リングの「ねじれ（Twist）」を完全に除去する [source: 5]。
    4. バックアップリング（スパイラル型）: 圧力のかかる下流側（低圧側）に配置し、回転体に取付ける場合は噛み込み防止のため「REVERSE CONFIG（左巻き/逆方向）」での装着を推奨する [source: 5]。

コントロールケーブル点検・テンションメーター計測 ↩️ リストへ戻る

  • 点検・損傷除去基準（AMM 20-20-02）:
    • ウエス擦り点検: ケーブルに沿って布（ウエス）を滑らせ、引っかかりで素線切れ（Broken Wires）を検出する [source: 5]。
    • 交換判定:
      • 7×7 ケーブル: 12 in (305mm) 範囲で 2本以上の素線切れ、または全超で 3本以上の素線切れで交換 [source: 5]。
      • 7×19 ケーブル: 12 in (305mm) 範囲で 4本以上の素線切れ、または全超で 6本以上の素線切れで交換 [source: 5]。
      • 素線摩耗が40%以上（平坦化）、キンク（折れ曲がり）、腐食、バードケージ（籠状膨らみ）発見時は即交換 [source: 5]。
  • テンション計測手順:
    1. TENSION METER、ライザー、換算表のシリアルナンバーが全て一致していることを確認する [source: 5, 6]。
    2. 測定場所はターミナルやスロットから 6 in 以上離れた直線部を選択する [source: 6]。
    3. 測定場所の外気温度を温度計（°F表示）で計測し、MM記載の「温度補正チャート」により適正テンション値（lb）に換算・判定する [source: 6]。

フルハーネス型墜落制止用器具・高所作業完全遵守 ↩️ リストへ戻る

  • 着用基準: 高さ 2.0m 以上の高所作業で、四方を囲まれた作業床が確保できない場合は「フルハーネス型墜落制止用器具」の着用が必須である [source: 4]。
  • 実技・落下距離短縮の3原則:
    1. フック取付け位置（アンカー）は腰より高い位置（できるだけ高い構造物）にセットする [source: 4]。
    2. ランヤードの長さは必要最小限（最短）に調整して使用する（常時巻取り型ロック装置付きを推奨） [source: 4]。
    3. フックを構造物に回してフック自身に引っ掛ける「通し掛け」は厳禁 [source: 4]。

有機溶剤・危険物使用中の養生と安全 ↩️ リストへ戻る

  • 容器管理: 有機溶剤容器は使用中以外、常にフタを閉鎖する [source: 3, 4]。
  • 換気: 局所排気装置の稼働または通風による換気を維持する [source: 3]。
  • 飛散防止養生（重要）: MPK および CEE-BEE 使用時、コロガードペイント塗装部（WING, H-STAB）やプラスチックパーツ（CABIN内）へ飛散すると塗装・素材を侵すため、必ずマスキング・ビニール等で徹底的に養生する [source: 3, 4]。保護手袋・ゴーグル・防毒マスクを着用する [source: 3, 4]。

特定作業（TCD / EMAR / CDCCL / DSMC / ASC / EC）の完全詳細 ↩️ リストへ戻る

① TCD (耐空性改善通報) 作業

  • 概要: 国土交通省航空局（CAB）が発行する耐空性改善命令（外国当局のAD等に基づく） [source: 8]。
  • 確認手順: MERS ORDER SHEETの Requirements 欄に「TCD」要件が記載されているか確認し、定められた期日・手順通りに確実に実施・記録する [source: 8]。

② EMAR 作業 (Emergency Equipment Related Work)

  • 概要: 航空法第150条等に定める非常用装備品（非常脱出スライド、ライフベスト、消火器、酸素マスク、ELT等）に関わる整備作業 [source: 8]。
  • 絶対ルール: 非常用装備品の Install や点検作業は、複数人による共同作業（手分け）は不可。責任ある1人の認定作業者が最初から完了まで完遂すること [source: 8]。

③ CDCCL 作業 (Critical Design Configuration Control Limitation)

  • 概要: Fuel Tank System 発火防止等のための重要制限作業（ATA 5, 12, 28, 29等） [source: 8]。
  • 絶対ルール: **AMM等の作業手順の変更・オミット（Deviation）は一切不可** [source: 8]。
  • MERS入力ルール: Confirmation の冒頭に必ず `CDCCL:` と明記し、規定値・ボンド抵抗値・使用した計測器管理番号（Torque Wrench/Bonding Meter）を正確に入力・記録する [source: 8]。

④ DSMC 作業 (Dual System Maintenance Control)

  • 概要: ETOPS機における同一の、または極めて類似した複数の ETOPS 重要系統（左右エンジン、左右HYD等）に対する同時不具合（Dual Maintenance）防止プログラム [source: 8]。
  • ルール: 複数系統に対する DSMC 対象作業を**同一の作業者が実施してはならない（原則、別々の作業者を配置）** [source: 8]。やむを得ず同一作業者が実施する場合は、IFVP（In-Flight Verification Program）を実施する [source: 8]。

⑤ ASC (Advanced Self Check) 作業

  • 概要: 過去の不具合・TFI（運航阻害）につながった作業に対し、QA Bulletin に示された「確かめ Point」を立ち止まって自ら確実に確認し、チェックを入れる [source: 8]。

⑥ EC (Enhanced Check) 作業

  • 概要: B787(ETOPS機) および B777-300ER のエンジン系（ATA 71~80）における Fuel/Oil Line 接続等の重要作業で実施 [source: 8]。
  • ルール: トルク締め等の重要ポイントにおいて、「作業者とは別の同一レベル以上の認定作業者（EC実施者）」が現場に立ち会い、二重で確かめ（ダブルチェック）を行う [source: 8]。
